# Changelog

## 1.0.0

First public release.

- Clipboard history for text and images, kept across restarts.
- Search, pin, remove and clear entries.
- Emoji picker with search, categories and a recently-used list.
- Pastes the chosen entry into the focused window, using the terminal paste
  shortcut in terminals.
- Non-modal popup: gestures, workspace switching and other shortcuts keep
  working while it is open.
- Settings window for the shortcuts, the history size and paste-on-select.
- Takes Super+V over from GNOME's notification list while enabled, and gives it
  back when disabled.
- Packaged as a .deb for Ubuntu 24.04 and as an extension zip.
